# Duke Farms Center for Conservation

Public repositories, datasets, and research tools supporting science and conservation initiatives at Duke Farms, a center of the Doris Duke Foundation.

## Focus Areas

- GIS and spatial analysis
- Biodiversity monitoring
- Hydrology and watershed science
- Ecological data management
- Conservation technology

## Repositories

These repositories are managed by the Duke Farms Center for Conservation team:

* [df_grasslandbird_pointcounts](https://github.com/dorisdukefoundation/df_grasslandbird_pointcounts) This repository contains code and data for grassland bird occupancy across Duke Farms. The code was written by Michael C. Allen, Ph.D., Tsuga Biodiversity Insights, LLC.

* [Duke_Farms_Camera_Trap](https://github.com/dorisdukefoundation/Duke_Farms_Camera_Trap) This repository maintains data and code for our site-wide camera trap array. At Duke Farms, we are interested in how wildlife on the property respond to the presence of our visitors.

## About Duke Farms

Duke Farms is a center of the Doris Duke Foundation focused on environmental stewardship, conservation, and applied science.
